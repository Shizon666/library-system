## 3. 核心约束（Core Constraints）

### 3.1 技术栈约束
- **不使用** Vue、React 等前端框架，仅使用原生 HTML5 + CSS3 + JavaScript
- **不使用** jQuery、axios 等第三方库，HTTP 请求统一使用 Fetch API
- **不使用** TypeScript，全部使用原生 JavaScript（ES6+ 语法）
- 页面布局采用**后台管理系统经典布局**：顶部导航栏 + 左侧菜单栏 + 右侧内容区
- 所有 HTML 文件通过 `index.html` 中的 iframe 或页面内联切换进行管理（单页应用风格），或使用独立的 HTML 页面通过超链接跳转

### 3.2 哑页面原则（与后端职责分离）
- **纯展示与交互**：页面只负责数据渲染和用户交互，不包含业务规则逻辑
- **不直接操作数据库**：所有数据通过调用 REST API 获取和提交
- **不实现业务校验**：借书上限、证件状态、罚款计算等业务规则由后端 Service 层处理
- **仅做前端格式校验**：如手机号格式、必填项检查、密码长度等

### 3.3 质量标准
- **语义化 HTML**：使用语义化标签（`<header>`、`<nav>`、`<main>`、`<table>`、`<form>` 等）
- **CSS 类名语义化**：使用 BEM 风格命名，如 `.sidebar__menu-item--active`
- **JavaScript 注释**：函数必须有 JSDoc 风格注释，关键逻辑行必须有行内注释
- **统一错误处理**：所有 Fetch 请求必须捕获异常并提示用户
- **响应式设计**：页面在 1024px~1920px 宽度下均能正常显示

### 3.4 性能要求
- CSS 和 JS 在 HTML 中通过外部文件引用（`<link>` 和 `<script src>`）
- 图片应使用占位图或 SVG 图标，避免外部依赖
- JS 脚本放在 `</body>` 之前加载
- 表格数据量较大时考虑分页显示

**必须实现以下功能：**

1. **基础 URL 拼接**：`API_BASE_URL + url`
2. **请求头自动设置**：`Content-Type: application/json`
3. **查询参数序列化**：将 `params` 对象转为 URLSearchParams
4. **请求体自动序列化**：`JSON.stringify(body)`
5. **响应解析**：统一调用 `response.json()` 解析
6. **错误处理**：
   - 网络错误（fetch 抛出异常）→ 提示"网络连接失败，请检查网络"
   - HTTP 状态码非 2xx → 提示相应错误
   - 业务错误（`code !== 0`）→ 提示后端返回的 message
7. **Token 自动注入**：从 `localStorage` 读取 token 并添加到请求头
8. **登录状态检测**：若后端返回 401，跳转到登录页

**参考代码结构：**

```javascript
const API_BASE_URL = 'http://localhost:8080/api';

function getToken() {
  return localStorage.getItem('token');
}

async function request(url, options = {}) {
  const { method = 'GET', body, params, silent = false } = options;

  // 拼接查询参数
  let fullUrl = API_BASE_URL + url;
  if (params) {
    const query = new URLSearchParams(
      Object.entries(params).filter(([_, v]) => v !== undefined && v !== null && v !== '')
    ).toString();
    if (query) fullUrl += '?' + query;
  }

  // 构建请求配置
  const config = {
    method,
    headers: { 'Content-Type': 'application/json' },
  };

  // 注入 Token
  const token = getToken();
  if (token) {
    config.headers['Authorization'] = 'Bearer ' + token;
  }

  // 设置请求体
  if (body && method !== 'GET') {
    config.body = JSON.stringify(body);
  }

  try {
    const response = await fetch(fullUrl, config);
    const result = await response.json();

    if (!response.ok) {
      // HTTP 错误
      if (response.status === 401) {
        localStorage.removeItem('token');
        window.location.href = 'login.html';
        return;
      }
      throw new Error(result.message || `请求失败 (${response.status})`);
    }

    if (result.code !== 0) {
      // 业务错误
      throw new Error(result.message || '操作失败');
    }

    return result;
  } catch (error) {
    if (!silent) {
      alert(error.message || '网络连接失败，请检查网络');
    }
    throw error;
  }
}

async function get(url, params) {
  return request(url, { method: 'GET', params });
}

async function post(url, data) {
  return request(url, { method: 'POST', body: data });
}

async function put(url, data) {
  return request(url, { method: 'PUT', body: data });
}

async function del(url) {
  return request(url, { method: 'DELETE' });
}
```

## 9. 安全规范

### 9.1 XSS 防护
- 所有动态渲染的文本内容必须使用 `textContent` 而非 `innerHTML`
- 如需使用 `innerHTML`，必须对用户输入进行 HTML 转义
- 严禁在 URL 参数中直接拼接用户输入

### 9.2 Token 管理
- Token 存储于 `localStorage`，key 为 `token`
- 每次请求自动从 `localStorage` 读取 Token 并注入 Authorization 请求头
- 登录成功后存储 Token，退出登录时清除 Token 并跳转登录页

### 9.3 敏感信息保护
- 前端日志禁止打印密码等敏感信息
- 密码输入框使用 `type="password"`
- 不在 URL 中传递敏感参数
