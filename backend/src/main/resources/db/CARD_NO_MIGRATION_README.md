## 在 192.168.110.191 上操作步骤

1. **备份** `library_db`
2. 执行 `verify_card_no_before_migration.sql`  
   - 第 4 段查询 **无结果** → 可直接迁移  
   - **有结果** → 把多出的 `C...` 证号按规则补进 `migrate_card_no_to_sno_suffix.sql` 的 `INSERT` 列表
3. 执行 `alter_libcard_sno_unique.sql`（若尚未执行）
4. 执行 `migrate_card_no_to_sno_suffix.sql`
5. 执行 `verify_card_no_after_migration.sql` 确认
